## 🚀 Topics & Key Contents

### 1. 🔢 Basics (`01-Basics/`)

- `01_hello_world.py`: Basic greetings and `print()` function.
- `02_comments_and_formatting.py`: Single-line, multi-line comments & escape sequences (`\n`, `\t`).
- `03_variables_and_data_types.py`: Variables (`int`, `float`, `str`, `bool`) and `type()` checking.
- `04_type_casting.py`: Converting between data types (`int()`, `float()`, `str()`).
- `05_user_input.py`: Interacting with user via `input()`.
- `06_f_string_formatting.py`: Modern string formatting using f-strings.
- `07_arithmetic_operators.py`: Math calculations (`+`, `-`, `*`, `/`, `//`, `%`, `**`).
- `08_comparison_operators.py`: Conditional relational checks (`==`, `!=`, `>`, `<`, `>=`, `<=`).
- `09_logical_operators.py`: Boolean logic operations (`and`, `or`, `not`).

## 🛠️ Prerequisites & Setup

### 1. Prerequisites

- **Python**: `Python 3.8+`
- **Database**: `MySQL Server`

### 2. Install Required Packages

```bash
pip install mysql-connector-python pymysql
```

### 3. Running a Script

Navigate to any directory and execute the Python script:

```bash
python "01-Basics/01_hello_world.py"
```
